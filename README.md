Bee-Baked-EV-Bot: The Ultimate 2026 Sports SyndicateThis repository contains a fully automated, high-frequency sports betting ecosystem designed to identify, log, and track +EV (Expected Value) opportunities across all major sports markets. By combining real-time API scanning, headless browser scraping, and advanced situational models, the Bee-Baked system operates as a professional-grade betting syndicate on autopilot.🚀 The Core ArchitectureThe bot is organized into a modular pipeline that handles everything from data acquisition to long-term performance accounting:Data Acquisition (The Scanners)Unified Scanner: A sequential, API-limit-protected bot that scans H2H, Spreads, and Totals for NBA, NHL, MLB, Soccer, and more.Smart Props Engine: Utilizes the /event-odds endpoint to find player props (Points, Assists, etc.) only for competitive games (Spread $\le 3$), maximizing API efficiency.Headless Scraping: Uses Playwright to scrape "soft" books like Bovada and Kambi-powered sites (BetRivers, Unibet) by mimicking human browser behavior.Edge Logic (The Predictive Models)NBA Fatigue Model: Detects rest advantages by identifying teams on the second night of a back-to-back.MLB Pitching Mismatch: Identifies games where the starting pitching ERA and WHIP differential exceeds 1.50/0.20, targeting the First 5 Innings (F5) market.NHL Goal Differential: Targets massive team quality gaps ($> 40$ goal differential) to hunt for high-value -1.5 Puck Lines.Automated ManagementCLV Tracker: Monitors Pinnacle (the sharpest book) to track Closing Line Value, ensuring your entries are beating the market.Auto-Grader: Automatically fetches box scores and grades every bet in your bets_log.csv as a Win or Loss.Weekly Accountant: Generates a Sunday-night executive summary of your total risk, net profit (units), and ROI.⚡ Clutch Moment NotificationsThe bot doesn't just log data; it pings your Discord with priority tiers:🟢 Routine Alerts: Standard +EV opportunities found during daily scans.🔴 Emergency Alerts: Detected edges greater than 5% that require immediate attention.🚨 Clutch Moment Alerts: High-value props found for competitive games starting in less than 60 minutes.🛠️ Setup & DeploymentThis syndicate is designed to run 24/7 using GitHub Actions, keeping you well within the 500-call monthly limit of The Odds API.Requirements: Install the environment using pip install -r requirements.txt.Environment Variables: Add your ODDS_API_KEY, SPORTS_GAME_ODDS_API_KEY, and DISCORD_WEBHOOK_URL to your GitHub Repository Secrets.Automation: The .github/workflows/ folder contains pre-configured schedules for morning grading, bi-daily scanning, and weekly accounting.
